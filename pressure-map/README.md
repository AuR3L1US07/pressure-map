# 学期压力地图 2.0

C# / .NET 10 / Avalonia 桌面应用。主界面采用 Filee 的浅色侧栏、暖灰背景、淡紫选中态与三栏布局；桌面待办使用与 DeskBox 相同思路的 Windows Explorer 桌面关联。

## 运行

双击根目录 `run.bat` 即可启动：它会关闭仍在运行的旧实例，只编译改动过的部分，然后运行最新代码，改完代码再点一次就能看到效果。`build.bat` 生成 `dist\PressureMap` 便携包（自带运行时，无需安装 .NET），供没有 SDK 的机器使用或对外分发；分发时请复制整个 PressureMap 文件夹。

要对外分发请用 `package.bat`：它会先生成最新的 `dist\PressureMap`，再产出两个文件——`output\installer\PressureMap-<版本>-setup.exe`（安装包，带许可协议页与安装位置选择）和同目录的 `PressureMap-<版本>-portable.zip`（免安装便携包）。安装包默认装到 `%LOCALAPPDATA%\Programs\PressureMap`，不需要管理员权限；向导第一步可以让用户切换成“为所有用户安装”（此时安装到 `Program Files` 并弹出 UAC）。卸载不会删除 `%APPDATA%\学期压力地图` 里的个人数据。

首次登录可选择“暂不登录”。原有 SQLite 数据保留在 `%APPDATA%\学期压力地图\pressure_map.db`，直接兼容旧版。新版界面配置存放在同目录的 settings-v2.json。账户缓存与游客数据隔离。

## 使用

AI助手默认使用服务端提供的 DeepSeek V4.1 Flash，无需填写 API Key，游客也可生成今日建议。补充要求与安排建议显示在页面顶部，课程和待办明细在下方。点击生成会发送当日课程、相关待办和补充要求；不会自动修改任务。共享密钥仅保存在服务端，不包含在安装包内。可在设置中选填自己的 OpenAI 兼容接口；清除自定义配置后恢复默认服务。

主窗口使用系统圆角（最大化时贴合屏幕边缘），标题栏已融入软件，支持拖动、双击最大化、最小化和关闭；窗口保留系统边缘缩放。启动时有轻微倾斜回弹，切换左侧栏目时右侧内容依次从上方落下。可在“外观”中开启“减少动画”；首次操作会立即结束启动动效。

界面支持中文与 English：在“设置 → 通用 → 界面语言”切换，切换后界面立即刷新，选择保存在 `settings-v2.json` 的 `language` 字段。调试时可用环境变量 `PRESSURE_MAP_LANG=en` 临时以英文启动；已打开的桌面组件在下次打开时应用新语言。

学期规划支持学期与课程管理、原始教学文本、复制 AI 提取提示词、导入 JSON、编辑任务、压力热图与开工安排。示例数据单独建立学期，不覆盖已有学期。数据页可导出 JSON 备份。

待办页可添加、完成、标记重要、编辑与删除任务，也可导入学期任务，重复导入不会重复创建。打开“接入桌面”后，待办关联 Explorer 桌面，不进入任务栏或 Alt+Tab，保持在普通应用下方；支持拖动、调整大小、锁定与折叠。关闭主界面时可通过系统托盘继续管理；退出程序会保存状态。Windows 桌面不可用时明确提示错误。

桌面待办只显示“还需要做什么”：一列待完成事项加截止信息，勾选即完成，子任务进度写在同一行而不展开。新增、编辑、删除、筛选、搜索、导入等操作都留在主界面的待办页；桌面上不再放任何管理按钮，右上角只有一个开合的锁形图标表示能否拖动，右键菜单提供“打开主窗口 / 锁定 / 隐藏此组件”。圆角交给 Windows 的 DWM 裁切，边缘带抗锯齿；窗口不描白边，只在左上角留一道高光，避免浅色壁纸上出现一圈白圈。

客户端和独立服务端支持软件内注册、登录与云同步，默认连接 `https://121.43.32.85/api`，无需填写地址或安装证书。登录窗口点击“没有账号？注册”即可创建账号并自动登录。课程、课表和待办同步到账号，其他设备登录同一账号即可恢复。登录后首次同步，此后每 30 秒检查更新；也可在“数据与备份 → 账号与云同步”点击“立即同步”。断网可继续保存，恢复连接后补同步；两端都有修改时暂停同步，备份双方版本并让用户选择。当前线上实例为 `https://121.43.32.85/api`，服务端源码在 `E:/AIGC/pressure-map-server`，部署与运维见该目录的 DEPLOY.md。详细协议见 CLOUD_API.md。

桌面待办默认启用磨砂玻璃：原生 Acrylic 模糊壁纸，前景文字保持不透明，配合圆角及高光边缘。可在“外观 → 桌面玻璃”开关效果、调整底色浓度；浓度越高越易阅读。无法使用原生模糊时自动采用清晰底色。

## 课程日历与今日课程

进入左侧“课程日历”→“导入课表…”，选择杭电教务处导出的文字版 `.pdf`、`.ics` 日历或 UTF-8 `.csv` 文件，检查预览后确认。重复导入同名文件会更新原课表；移除单份课表不会影响学期任务或待办。ICS 支持每周、单双周、停课例外和调课；带时区的事件按本机时区显示，无时区的时间按本地时间显示。全天事件会在导入预览中提示，不作为课程显示。

CSV 使用“日期、课程、开始时间、结束时间、教室、教师”列（后两列可选），日期 `yyyy-MM-dd`，时间 `HH:mm`；每一行是一堂具体日期的课。可直接下载模板后用 Excel 编辑，并另存为“CSV UTF-8”。PDF 导入时先选择学期，目前预设杭电 2026—2027 学年第一学期（下沙校区）：9月14日为第1周，新生9月21日从第2周开始；按周次和单双周展开，中秋、国庆、元旦停课，9月20日补10月6日、10月10日补10月7日，1月10日起停课考试及寒假。校庆未注明停课，不额外取消。预览中可以另存 ICS，再确认导入；无星期和节次的“其他课程”不导入。仅支持文字版教务课表，不支持截图、扫描 PDF 或 `.xlsx`。

开启“在桌面显示今日课程”后，会出现与待办风格一致的独立玻璃栏目，显示上课时间、教室和正在上课/未开始/已结束状态。它与待办分别保存位置、锁定和折叠状态，关闭主界面仍可保留于桌面；从系统托盘可重新显示。日期栏可切换其他天，点击“今天”恢复跟随今日；跟随今日时自动跨日更新。

课程日历源随 JSON 备份及账户快照同步；窗口位置、玻璃和提醒投递状态保留为设备本地设置。

## 今天、作业与每日压力

启动后进入“今天”，顶部概览显示今日课程、今日待办和待提交数量，并提示逾期或最近截止事项；下方两栏查看课程日程和当天任务，课程区优先展示正在上课或下一节，已结束课程可折叠。快速添加会安排到今天；详细新建可关联课程、选择作业/考试/复习/实验/报告类型、填写预计耗时、精确截止日期与时间，并拆分最多 20 条子任务。课程卡片的“＋”可直接为这门课创建任务。

勾选“需要提交”后，“做完”和“提交”分别记录；做完但尚未提交的任务继续留在今天视图，可点击“标记已提交”。未设置具体截止时间时按当天 23:59 处理。

每日压力以圆环显示 0～100 分，软件和独立桌面玻璃栏目使用相同算法。压力圆环只出现在首页顶部和桌面玻璃栏目，设置页不再放预览。在“设置 → 每日压力”可调整每日容量、开启“在桌面显示压力圆环”，也可从托盘打开；计算方式在点击圆环后的“每日压力怎么算”中查看。分数变化有短暂透明度反馈，“减少动画”时关闭。算法包含课时、预计耗时、类型、紧迫度和子任务进度，主要来源在桌面栏目列出。每天容量默认 6 等效小时，范围 1～16。详细规则见 DAILY_PRESSURE.md。

提醒在截止前一天、一小时和到期时检查，以软件内提醒浮层显示，支持延后 15 分钟，状态会保存避免重复提醒。需要软件持续运行；有待提醒任务时关闭主窗口会留在托盘，明确从托盘退出后停止提醒。可在“设置 → 任务提醒”关闭截止提醒。

原有数据库兼容保留，新增详情单独存储，任务、子任务与提交状态随 JSON 备份导出。学期规划中的任务需通过“导入当前学期任务”转为可完成的待办后，才纳入每日任务负荷。

## 快捷操作、备份与桌面管理

任务“⋯”菜单可推迟安排到明天，原始截止日期保持不变。清单右上角“⋯”可展开搜索、选中当前列表、批量完成或撤销最近删除。批量完成只表示做完，需提交的任务仍单独确认提交。任务少时首页收起搜索框。详细编辑中的重复间隔设为 1、7、14 等天数；0 表示不重复。任务完全结束后才生成下一次，重置子任务进度；错过的周期会跳到下一个未来日期，不生成大量逾期副本。

“数据与备份”支持立即备份、导出、选择历史备份或文件预览恢复。每天首次检查自动备份，保留最近 14 份日备份；删除、恢复和同步冲突另存备份。恢复会替换当前本机或账户数据，先显示学期、课程、待办和课表数量；确认前若数据已有新修改则拒绝覆盖。登录账户中恢复的数据会参与后续云同步。撤销最近删除仅在删除后没有其他数据修改时直接生效，否则请在备份中预览恢复。

备份目录为当前数据目录的 `backups`，含私人学习数据，分发软件时不要附带该目录。手动备份和恢复前备份不会自动清理，定期将需要保留的备份复制到其他设备。

“数据与备份 → 本地缓存”显示当前占用并支持一键清除。清除范围包括网课课程记录、已保存的网课账号与登录状态、临时残留和应用日志（`native.log`、`startup-error.log`），并覆盖游客目录与各账号目录；学期与任务数据、课表和备份都不受影响，清除后需要重新登录网课助手。

“设置 → 桌面组件”集中管理三个栏目，支持显示、隐藏、锁定、折叠和独立鼠标穿透。穿透后可在设置中关闭，也可从托盘打开主窗口后“恢复全部组件交互”。拖到屏幕工作区边缘 20 像素附近，停止拖动后自动吸附；开关可关闭。成功提示 5 秒后收起，错误提示保留以便处理。

游客数据与账号缓存不自动混合。首次登录后，可在“账号与云同步”选择“将本机数据复制到当前账号”，确认数量后复制；账户缓存必须为空，以免覆盖现有云数据。退出登录保留账户缓存，并回到原游客数据。密码和会话令牌只留在内存，重启后需要重新登录。

## 源码开发

安装 .NET 10 SDK，或使用工作区 `.tools\dotnet` 的 SDK：

- `powershell -ExecutionPolicy Bypass -File dev.ps1 -Mode Run`：编译并启动。
- `powershell -ExecutionPolicy Bypass -File dev.ps1 -Mode Check`：运行核心回归检查并编译界面。
- `powershell -ExecutionPolicy Bypass -File dev.ps1 -Mode UiCheck`：使用独立临时数据验证界面与桌面关联。
- `build.bat`：测试并生成 Windows x64 自包含便携包。
- `package.bat`：生成便携包后编译安装包与便携 zip，产物在 `output\installer`。等价于 `dev.ps1 -Mode Package`（不重复跑测试）。安装包脚本为 `installer\PressureMap.iss`，许可协议全文为 `installer\EULA.txt`，两者都是纯打包配置，不参与 C# 编译。
  安装包需要 Inno Setup 7 的 `ISCC.exe`；工作区已备便携版 `E:\AIGC\.tools\innosetup`，`dev.ps1` 会依次查找工作区、`Program Files` 与 `PATH`。若换机器，可用 `innosetup-7.1.0-x64.exe /PORTABLE=1 /VERYSILENT /DIR=<工作区>\.tools\innosetup` 重新部署。

`PressureMap.slnx` 为解决方案；`src/PressureMap.Core` 包含规则、SQLite 与网络接口；`src/PressureMap.App` 包含 Avalonia 页面和 Windows 桌面服务；`tests/PressureMap.Checks` 包含回归检查及旧版数据库夹具。schema.sql 与 static/sample.json 是运行资源。

旧 Python 源码已备份至 archive/python-before-csharp.zip。参考来源和许可证见 DESIGN_REFERENCE.md 与 THIRD_PARTY_NOTICES.md。

## 网课助手

支持学习通和中国大学 MOOC / SPOC 的课程任务统计。点击“登录账号”进行后台登录；错误密码、验证码和网络超时会在登录弹窗内反馈。密码框右侧的眼睛按钮可以切换密码显示。默认保存账号信息并自动登录，启动扫描默认关闭，手动登录成功后自动读取课程。

详细操作、账号保存规则与开发模块见 [网课助手说明](docs/ONLINE_COURSES.md)。项目结构及清理方法见 [源码目录说明](docs/SOURCE_LAYOUT.md)。
