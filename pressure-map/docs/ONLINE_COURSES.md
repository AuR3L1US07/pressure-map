# 网课助手

主页面保留平台选择、读取课程任务和登录账号。支持学习通及中国大学 MOOC（含 SPOC），只读取课程页面、考核规则和提交记录，不播放课程、不答题、不提交作业。

## 登录与账号

点击“登录账号”输入账号密码，密码框右侧眼睛按钮切换显示和隐藏，默认隐藏。账号密码登录全程在后台执行；错误密码、验证码要求和网络超时在弹窗内反馈，保留输入并允许重试。后台登录设有超时保护。只有主动点击弹窗“自动登录”右侧的“网页登录”才打开浏览器。

“保存账号信息”和“自动登录”默认勾选。关闭保存时不将账号密码写入磁盘；关闭自动登录时不在后续启动中恢复会话或使用保存账号自动登录，当前运行期间可继续使用已登录会话。手动登录成功后自动读取当前平台。

账号及持久会话经 Windows DPAPI 加密保存在当前数据目录的 `online-courses` 文件夹，不加入账户云同步或 JSON 备份。更换平台账号会清除旧会话及课程读取记录。网页登录成功后清除该平台原有密码和课程记录，避免账号混用。

## 课程读取与设置

“读取课程任务”展示平台可读取的任务点、课件、作业、测验、讨论、活动与学习次数。未识别数据标记“待确认”；每门课程显示读取时间，读取失败保留已有课程列表。两平台提供的统计项不同，界面按实际数据展示。

“设置 → 网课助手”包含：

- 启动时自动扫描网课：默认关闭；开启后，下次启动扫描允许自动登录且已保存账号或会话的平台。
- 平台账号：选择学习通或中国大学 MOOC，清除账号、会话及本机课程读取记录。

点击“登录账号”会停止旧操作再打开弹窗，以便重新登录。

## 开发与分发

- `src/PressureMap.App/OnlineCourses/`：后台浏览器读取及登录脚本。
- `src/PressureMap.App/OnlineCourses/.runtime/`：随程序分发的 Node.js、Playwright Core 和许可证，是必需依赖，不能作为缓存删除。
- `src/PressureMap.App/Services/OnlineCourseService.cs`：进程通信、加密保存和取消控制。
- `src/PressureMap.App/Views/MainWindow.OnlineCourses.cs`、`OnlineLoginDialog.cs`：页面与登录弹窗。
- `tests/OnlineCourses/`：登录、超时、课程统计和运行时回归检查。

需要本机安装 Chrome 或 Edge，运行时已随发布包携带，不依赖原先的 `E:\刷课` 工程。

运行回归检查：

```powershell
src\PressureMap.App\OnlineCourses\.runtime\node.exe --test tests\OnlineCourses\*.cjs
```

## 读取进度与失败恢复

点击“读取课程任务”后，原按钮会变为“取消读取”，下方临时显示连接、登录检查、课程列表及任务统计进度。主动取消会保留已经读取的结果并恢复按钮。

失败时显示实际原因：未登录或会话失效、账号密码错误、验证码要求、网络或代理异常、页面超时、缺少浏览器、进程异常退出等；按钮变为“重试读取”，也可以直接重新登录。平台连续 90 秒没有任何进度时自动停止；单次读取最长 10 分钟，避免一直锁住界面。主动网页登录保留人工验证时间，不应用 90 秒无进展限制。

## 横向课程进度表

课程按行展示，上方横向切换学习通的任务点、作业、讨论、活动、学习次数，或 MOOC 的课件、测验、作业、讨论。表格显示课程名称、要求、已完成、剩余、完成进度、状态和检查时间；完成进度包含百分比与进度条。点击表头排序，可以调整列宽和列顺序。

“无此要求”不计算百分比，“待确认”不会被当成零或已完成。选择待确认行可查看原因。学习次数超过零但要求为零时，保留实际次数并标注无此要求。当前分类顶部显示课程总数和各完成状态的数量；未将不同计量单位相加。
