# 动画、错位与桌面待办样式修复

## 原因与修改

- 旧页面动画通过界面线程16ms定时器驱动，和页面构建/课程加载争用；另有整窗旋转与分组延迟入场。移除这些逐帧回调，改为单个内容区域的180ms合成淡入，保留减少动画开关。
- 在调试合成位移动画时，直接动画化布局拥有的Offset导致内容向左上方偏移、遮住标题。此实现已撤除；最终版本不改变Offset、RenderTransform、尺寸或页面位置。
- 今天页仅在跨越单栏/双栏断点时重建Grid定义，避免每次尺寸变化都重建布局。
- 桌面玻璃样式曾为整个CheckBox设置半透明白底，因此子任务文字后出现矩形白块。现将复选框及标签容器背景设为透明，选中任务仅使用淡紫提示。
- 通用按钮显式设置水平/垂直内容居中，多行按钮文字居中；单行输入文字垂直居中。任务标题和说明保持左对齐，统计信息不强制居中。
- 主任务勾选框/操作按钮与标题顶部对齐；子任务勾选框与文字垂直居中。修正32px操作按钮被放入28px列的问题。
- 桌面待办图标改为任务列表语义，避免缺失图标回退成info。

## 验证方式

- Release构建。
- 导航快速切换、减少动画和完整界面功能回归。
- 今天、通用设置、外观、待办切换过程中分别截取三帧；检查标题/内容不重叠，且没有残留布局变换。
- 桌面带子任务的选中任务截图；检查复选框标签背景透明、操作按钮居中。
- 中英文、960×640和1180×820、浅深主题页面截图回归。

上述检查不等同于真实设备帧率测量，不宣称已经达到固定60/120fps。合成动画运行方式依据[Avalonia官方说明](https://docs.avaloniaui.net/docs/graphics-animation/composition-animations)。

验证结果和截图位于`interaction-fixes/`。
