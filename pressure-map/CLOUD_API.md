# 客户端登录与云同步

独立服务端位于 `E:/AIGC/pressure-map-server`，完整接口和部署说明见该目录的 API.md、README.md。客户端同步引擎为 `src/PressureMap.Core/CloudSyncEngine.cs`，事务导入和备份为 `Store.Snapshots.cs`。

## 使用

默认连接 `https://121.43.32.85/api`。登录窗口点击“没有账号？注册”，填写账号、显示名、密码和确认密码，注册成功后自动登录并同步。首次登录空账号时可以确认复制已有本机课程、课表和待办。

登录和注册窗口不再显示服务地址。自建服务仍可使用 `PRESSURE_MAP_API_URL` 环境变量提供地址。请求不跟随重定向，超时 30 秒。

登录后自动同步一次，此后每 30 秒轮询，也可点击“立即同步”。左下角显示头像、名字和同步状态（已同步、离线待重试、会话过期或冲突），点击进入“账号与云同步”；退出登录也在该卡片的“退出登录”按钮。断网不影响本地保存；会话令牌过期后需退出到本地模式并重新登录。退出尝试撤销服务端令牌，即使网络不可用也可回到本地模式，未撤销的远端令牌按服务端期限过期。

## 同步规则

- 按服务器地址和稳定用户 ID 的哈希隔离账户缓存；游客数据保持独立。
- 同步学期、课程、课程任务、待办全部详情（含重复间隔 repeat_days、子任务与提交状态）、ICS/CSV 原文。
- 每账号在缓存目录保存上次 revision 和规范化内容摘要，不保存密码和令牌。摘要忽略导出及更新时间，并归一化课程数据库 ID，避免下载重建 SQL ID 产生假变更。
- 仅本地变化时按基准版本上传；仅云端变化时，校验格式并备份，再通过一个 SQLite 事务导入。网络请求期间本地有新编辑或正在编辑表单时拒绝覆盖，之后重试。
- 双方都有变化或上传版本失效时暂停，保留本机和云端备份。冲突预览显示双方数量和部分待办，选择一份作为当前版本；不做字段级自动合并。取消不覆盖任何数据。
- 选择云端前再次检查云版本；选择本机也必须通过服务器版本检查。选择过程中任一端再次修改，需要重新同步确认。
- 上传成功响应丢失时，下一次先比对云端内容，避免盲目重复上传。
- 恢复备份属于一次本地修改，会参加后续同步；缓存已有数据时，不允许直接把游客快照覆盖进去。

## 接口兼容

`POST /v1/auth/login` 使用 account/password，响应 access_token、user{id,name}。

`GET /v1/data` 响应 `{revision,snapshot}`；初次 revision 为 null。`PUT /v1/data` 请求 `{base_revision,snapshot}`，返回新的 revision。认证使用 Bearer 令牌；401 清除内存会话，409 进入冲突处理，网络错误保留缓存和同步基准。

`POST /v1/auth/logout` 撤销当前会话。服务端也支持管理员创建、重置密码和禁用账号；桌面支持公开注册，暂不提供邮件找回密码。

服务端已部署在阿里云 `https://121.43.32.85/api`。该实例暂无域名，使用自签证书，客户端内置该 IP 的证书 SHA-256 指纹校验，无需手动安装证书；接入正式域名后改用公共 CA 签发的证书。其他服务地址使用系统 HTTPS 校验；默认 IP 仅额外接受已核对指纹、主机名和有效期的证书，证书轮换时需要更新客户端指纹。设备设置、提醒投递状态、密码和令牌不进入快照。备份及本地数据库未做应用层加密。
