# 控件居中检查与修复

本轮范围包含十个页面内容、中英文、浅深主题、960/1180宽窗口、规划四个步骤、登录/确认等弹窗、桌面待办。只处理需要居中的文字与图标，保留标题、正文、任务内容和表格数字原有的阅读对齐方式。

## 已修复

- 周日期块、今天按钮、卡头/空状态的管理课表按钮：字符串由主题模板生成，之前只设置外层对齐或普通后代选择器不足以覆盖。现在使用显式居中文字模板，并对实际ContentPresenter设置居中。
- 通用按钮、胶囊、过滤按钮、分类标签、弹窗操作：共享文字模板；Content继续保留字符串，语言切换、读取/取消/重试等动态文案和原有处理不变。
- 图标加文字按钮及纯图标按钮：整体内容居中。账号卡、统计信息等明确采用左对齐或拉伸的复合内容不强制居中。
- 学期压力地图：单侧3dip警示边框曾使数字上偏约1.6dip，改用不参与按钮布局的覆盖线；周数表头居中。
- 快捷键键帽、计数胶囊、网课状态块：文字水平/垂直居中。
- 压力圆环：分数与“/ 100”在同一条中轴线上。

## 验证方法

测量实际生成的文字、图标或内容组的边界中心，与所属按钮/标签的边界中心比较，容许1dip以内的像素取整误差。它不是仅检查Center属性。矩形键帽的不对称底边会产生0.5dip以内的视觉偏差。

检查结果详见`centering/centering.json`，完整功能回归详见`centering/smoke.json`。截图同目录保存今天页、压力地图、网课表格、快捷键和弹窗等代表页面。

最终结果：2289次位置检查通过，最大水平偏差0.4dip，最大垂直偏差0.8dip；Release构建与完整界面回归通过。
